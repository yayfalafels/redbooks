# Open lessons

Lessons to be learned for the tracker process. Each is unsettled practice. Observe it, record what happens as `lesson observation LT.NN` in the tracker's Validate section, and present it as a hypothesis, never as a rule.

## LT.07 trial skill changes before promoting them

**status**: experimenting

**question**: does a change to a skill or an agent change what the agent does?

**evidence that settles it**: a trial where the control fails and the experiment passes, against criteria set before the run. Any other outcome is no evidence.

**experiment**: trial three skills on representative tasks, each run once with the skill as it was and once with the change.

## Experiment section

A tracker that runs an open lesson experiment adds this section to Validate, filled in before the run except for the result.

```md
### experiment LT.NN <title>

01. **hypothesis**: <what the change should cause>
02. **control**: <the run without the change, and its inputs>
03. **change**: <the one thing that differs in the experiment run>
04. **criteria**: <pass and fail conditions, set before either run>
05. **result**: <control outcome, experiment outcome, and whether it counts as evidence>
```
