# Open lessons

Lessons to be learned for frontend practice. Each is unsettled. Observe it, record what happens as `lesson observation LT.NN` in the tracker's Validate section, and present it as a hypothesis, never as a rule.

## LT.04 move a walkthrough earlier

**status**: experimenting

**question**: does a short human walkthrough of a rough page early in a feature reduce the late interface feedback?

**evidence that settles it**: the count of interface items found after automated validation, compared with a feature that had no early walkthrough.

**experiment**: walk through the first data entry page at phone width before its tests are complete, and count the items found early and late.
