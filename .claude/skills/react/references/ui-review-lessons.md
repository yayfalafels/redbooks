# UI review lessons

The user's standing interface preferences, gathered from walkthroughs after the automated checks had passed.

## Lessons

### apply the human walkthrough's interface feedback

Apply these preferences to every page.

01. label every control, and space sections apart.
02. show list data in a table with aligned columns.
03. put a detail view's primary actions at the top.
04. hide internal ids.
05. offer search, sort and batch actions on long lists.
06. discard unsaved edits when another record opens.
07. return to the list after a save.
08. keep one navigation control per feature.
09. show a status beside the control it belongs to.
10. reserve each color for one meaning.
11. keep a result dialog open until the user closes it.

**why**: two walkthroughs produced about forty interface items after every automated layer had passed, and the same themes recurred across features.

Example: an entry detail page shows Save and Delete at the top, labels the amount field, hides the entry id, and returns to the account's entry list after Save.
